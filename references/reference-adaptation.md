# 参考图适配

用于用户要求模仿科研架构图、复杂技术路线或信息丰富的学术页面时。简单改字不需要新建参考分析。

## 提炼可以迁移的组织方式

实际查看参考图，记录以下与本次设计有关的内容即可：

| 观察 | 记录什么 | 制作时如何使用 |
| --- | --- | --- |
| 核心对象 | 中心是研究目标、机制、算法还是评价对象 | 替换为本课题真正需要解释的对象 |
| 分组与层级 | 两侧支撑、上下推进、多尺度或并列比较 | 根据内容决定保留、合并或拆分 |
| 连线 | 因果、数据依赖、比较、反馈或包含 | 标明起终点和含义，不能复制未获证据的因果 |
| 配色角色 | 输入、方法、证据与边界 | 同类对象整套保持同一含义 |
| 证据位置 | 原图、测量、表格、局部放大 | 放入真实相关证据，细节另页展开 |
| 阅读顺序 | 整体到分支、左到右、分层推进 | 正文给出足够引导，不能只靠讲稿解释 |

参考记录可以是几行制作笔记，不强制产生额外文件。私有截图只用于本地参考，不随公共技能发布。字体、LOGO、宣传语、水印和原专业标签不属于可自动迁移的内容。

## 图的目的决定箭头

- 研究框架：解释问题、方法和证据怎样对应，连接表示支撑或任务分解。
- 科学机制：只绘制有出处的关系，推测关系用虚线并给图例。
- 技术路线：显示输入对象、操作和实际输出。上一层输出应成为下一层明确的输入。
- 结果图：保留对照、单位、样本、条件与不确定性，示意图不能替代实验结果。

图中的回路必须指向真实可修改的环节。复杂图给出线型图例，避免一个箭头同时承担时间、因果和信息流。电气连接示意应区分物理连接与算法计算依赖。

## 在真实内容中试排

选一页关系最丰富的图和一页真实结果图先检查：核心对象能否识别、关系能否沿线读出、缩略证据是否有用、文字是否可读。获准整套制作时继续完成，不新增审批阶段。

保留用户要求的信息密度。总览页用于看关系，后续页用于解释关键分支。放不下时按逻辑拆分、放大证据或调整位置，不能删掉科学前提。

## 密集构图与图片路线

将参考与样页放在相近尺寸比较：是否都有完整主图、分层或中心关系、两侧支撑、局部科学示意及验证出口。比较的是表达任务，不以形状数量作为质量分数。参考中有模型网络、样本矩阵、物理结构和限值示意时，本课题也应提供对应的有用细节；不能仅替换为几个大框或空白容器。

- 原生方式：适合需要频繁修改标签、变量和连接的技术图。
- 图片方式：适合复杂科学构图、插画、原图及用户接受整体编辑的科研图；保留清晰原图并按比例嵌入。
- 混合方式：图的结构或插画用图片，页面标题、结论、图注及定量结果用原生文字、表格和图表。

用户明确接受图片时可直接采用图片路线，不重复征求许可，也不以可编辑性为由降低视觉复杂度。未指定时根据图的用途取舍，并在交付中准确说明。不要把图片称为元素级可编辑。

生成概念图前给出准确短标签、关系和禁止编造项。生成后逐项核对变量身份、公式、箭头、中文和图例；“看起来专业”不能替代科学核对。修改后复查整张图。原文结果不能由图像模型重画猜数；保留真实数据的原生图或原作者图并注明来源。示意曲线去除无意义的数值刻度并标明非实测，提出的研究路线标明待验证。

优先保存足够清晰的图像，避免把整张手机宣传截图放进正文。以实际插入尺寸检查关键字，必要时增加同主题展开页或局部放大。原始图、图意说明和文字提纲按需要保留，便于下一次修改。
