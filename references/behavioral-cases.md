# 技能行为用例

维护技能时，用真实范围的请求检查实际产出。这里是可重复的用例，不是每次制作须执行的额外流程。普通PPT制作无需加载本文件。

| 请求 | 可观察的检查 |
| --- | --- |
| “只审阅这份PPT，先不要改文件。” | 输入文件哈希保持不变；输出有页码、具体对象、影响和修改建议；未创建替换版整套PPT |
| “只改第2页的一个标签，其余页保留。” | 目标标签修改；其余页文本、关系、表格、数据与备注保留；新文件存在，改动页重新渲染 |
| 只给一段摘要，要求方法与结果页 | 不编造样本数、参数、图像和显著性；明确实际支持内容与缺失项；不把提纲冒充已导出的PPT |
| 原文摘要、正文与结果表的值冲突 | 记录各位置与口径；不取最大值或平均值；保留待核对标识，不受影响的内容继续制作 |
| 本次要求现场讲解，本地默认是独立阅读 | 应用本次密度要求；关键指标与条件仍在正文；不自动追加另一版本 |

评价时比较文件和任务范围，不要求出现固定标题或措辞。异常应先确认来源、操作和输出，再作小范围修改。

公开论文案例实际遇到了来源冲突，页面和备注保留了差异。包检查的自测试通过删除资源、损坏PPT、去除备注、删除原生表格、改变图表缓存和插入私密配置，确认检查器会拒绝损坏包。它不能代替技能的实际任务试用或人的科学审阅。

## 第二版的实际试用

2026-10-10，在隔离目录由独立评估者完成三次请求，随后核对实际输出：

- 只审阅：输出覆盖8页的具体意见；输入文件SHA-256保持不变，未交付替换版PPT。
- 单页修改：另存PPTX，仅第2页标题改变；其余包部件内容逐字节一致，改动页已重新渲染查看。
- 摘要不足：输出三页内容方案；方法、指标、数据、样本和机理明确待补，未编造数值或显著性。

这些结果支持上述三类请求的范围控制，不保证所有未来请求都会正确执行。另在临时副本中修改原生文字、表格单元格和图表数据，保存并重新导入后核对修改值。渲染使用Artifact Tool；未在Microsoft PowerPoint中人工验证。
