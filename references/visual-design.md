# 视觉与科研配图

## 从参考关系出发

实际查看用户给出的参考图。提炼视觉语法：主次层级、中心与两侧关系、模块尺寸、证据缩略图位置、配色角色、箭头形式和留白。不照搬其中的专业内容、品牌或宣传文字。

用户喜欢信息丰富的科研架构图时，保留多模块之间的关联与必要解释，同时根据最终投影尺寸放大关键对象。手机截图中能放很多元素，不代表每个小字都适合直接投影。

| 内容关系 | 可选表达 | 核心检查 |
| --- | --- | --- |
| 数据到成果的操作链 | 横向流程、上下泳道 | 输入、动作和产出分别可见 |
| 一个研究问题与多类支撑 | 中心问题、两侧方法与证据 | 核心对象突出，连接含义明确 |
| 机制、多尺度或分层方法 | 分层结构、局部放大、机制环 | 层级真实，跨层关系有依据 |
| 前后变化或方法比较 | 左右对照、比较矩阵 | 比较对象、条件和尺度一致 |
| 验证与反馈 | 实线流程、虚线反馈 | 反馈回到哪一步、为何反馈 |
| 实验结果 | 主结果图加必要辅图 | 图例、误差、样本和条件完整 |

可以集成多个相关图，或在总架构图旁嵌入原始证据小图。小图必须有明确用途和可辨识内容；需要读细节时安排放大页或局部放大，不把缩略图当装饰。

## 给图形一个语义

配色用于区分角色，例如输入/方法/证据/验证；具体颜色可随参考和学科调整。整套PPT保持同类对象的颜色与形状含义一致。避免每个模块使用不同颜色而没有分类意义。

实线、虚线、双向箭头、回路和包含框要有明确含义，复杂图需要图例。箭头应能指出起点、终点和关系，尽量避免穿字、无意义交叉或多个含义混用。流程中的回路不应让读者误认为结果已确定。

布局由内容关系决定，模块只是容器。允许圆环、中心辐射、三列、三角与多层结构；不要为追求丰富而增加不存在的层级或联系。

## 投影可读性与一致性

以最终页面尺寸、屏幕比例和观看距离检查字号，而非设置不分情况的最小字号或每页字数。标题、正文、图注和页脚各有稳定层级；重点说明与装饰标签有明确区别。

优先统一字体、标题起点、外边距、图注、页码和对齐。正文用适合中文的清晰字体，公式和拉丁符号保持可读。留白服务于分组，不能把必要解释挤到备注中。

用总览检查整套的节奏，用单页检查细字、连接线和图例。密集总览图可先讲整体，再在后续页放大关键分支，避免靠动画或口述才能读懂整页。

## 可编辑性与素材

可重建的数据图和表格优先采用PPT原生对象。技术图根据本次要求选择原生或图片，复杂构图可直接作为高清图片嵌入；不要为了原生对象而简化用户要求的科研图效果。标题、结论与图注保持独立，说明哪些图像只能作为整体图片编辑。

插入SVG后，不假定所有播放器都支持元素级编辑；需要时另附SVG源文件，并在目标PPT工具中检查显示效果。透明度、字体、裁剪和箭头端点应实际检查。

只用来源明确、适用权限清楚的素材。用户提供的截图可以作为本地风格参考，但未获相应许可不能发布到公开图库或仓库。不要去除水印以冒充原创，也不要直接使用低清晰度宣传拼图作科研证据。

AI生成图可用于概念示意或插画；真实实验图、统计结果、分子结构、系统连接和流程事实仍需核对。涉及科学判断的对象优先用可检查的图元，不让生成模型猜标签或关系。

## 图库的维护

公开图库保存可公开的原创或获许可样图，并记录用途、布局关系、配色角色、可借鉴点和不宜照搬的地方。私有项目截图、用户资料和许可不明的参考图保留在本地目录，不随技能发布。

新增样图应来自真实使用中有帮助的表达，不为凑数量扩充图库。优先复用组织关系，每次仍根据实际内容重新判断。
